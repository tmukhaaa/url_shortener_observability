# Сервис коротких ссылок с мониторингом

Сервис на Go для создания коротких ссылок. В проекте настроены метрики Prometheus, дашборды Grafana, проверка состояния и хранение данных в SQLite.

## Настройка базы данных

Сервис использует SQLite. По умолчанию при запуске он создаёт файл `storage.db` в папке проекта. Чтобы использовать свой файл базы, укажите путь к нему в `storage_path` в `config/local.yaml` или `config/prod.yaml`:

```yaml
storage_path: "/путь/к/вашей/storage.db"
```

Выбрать конфигурационный файл можно с помощью переменной окружения `CONFIG_PATH`. При запуске приложение автоматически создаёт таблицу `url` и индекс для коротких имён ссылок. Добавьте файл базы в `.gitignore` и не храните его в Git.

## Запуск приложения

```sh
CONFIG_PATH=config/local.yaml go run ./cmd/url-shortener
```

Если используете другой файл базы, измените `storage_path` в выбранном конфигурационном файле.

## Мониторинг

Запустите Prometheus и Grafana командой:

```sh
docker compose -f docker-compose.monitoring.yml up -d
```

Приложение предоставляет метрики по адресу `/metrics` и проверку состояния по адресу `/healthz`. Настройки Prometheus и файлы для автоматической загрузки дашборда Grafana находятся в папке `monitoring/`.
